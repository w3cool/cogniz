# 标的分析对话

参考 2026-10-03 截图中的生成顺序，实现链路为：选择分析框架 → 解析证券及交易日期 → 采集行情和历史数据 → 计算指标 → 补充新闻与财报证据 → 核验 → 交付分章节报告与图表。`longbridge-sample-conversation-result.md` 当前为空，未据此填入示例行情或报告数字。

## Agent、Skill 与 Tool

`market_analyst@1.0.0` 为近期行情、走势、综合研究选择 `security-research@1.0.0` 及资讯搜索。bundle 已覆盖日线、区间表现和技术指标，不再同时选择依赖这些单独历史工具的 Skill，避免数据缺口触发换工具重复请求；公司对比继续使用自己的 Skill 和比较工具。代码注册表和后台启停策略继续决定工具权限，已有 Run 使用入队时的版本、摘要和预算。

`market_analysis_bundle@1.0.0` 集中采集单只沪深 A 股的报价、估值、60–300 条日线，默认请求 180 条。报价和历史并行读取，估值复用报价响应；完整序列交给确定性 Python 函数计算，而非让模型生成或执行脚本。单个 Tool 调用不等于单个 HTTP 请求，Provider 预算、限流、缓存和恢复快照继续分别执行。

报告采用 `MarketReportOutput`，包含原有事实/引用字段、章节及最多三个追问建议。完整章节同步进入可读 Markdown，再接受既有 verifier 检查。工具返回的图表列不进入模型上下文；Agent 的 `artifact_builder` 从摘要校验后的完整工具结果生成交付物，避免模型改写曲线数字。

资讯搜索继续使用 `/admin/search-providers` 的百度搜索配置。Skill 先进行最多两次聚焦检索，必要时在剩余预算内补证；接口不支持的财报和资金数据不反复换参数调用，直接说明缺口并寻找带日期的公开材料。

## 对话界面

- 分析过程：实际 Skill、Tool、采集/计算状态、失败和校验结果可折叠查看，运行时经现有 SSE 持续更新。已有供应商 reasoning 保留独立折叠区。
- 工具详情：点击 Tool 打开侧栏，显示脱敏请求与真实响应，可复制 JSON；完整响应按需从归属校验接口读取。
- 报告：支持行情概况、趋势、关键价位、量价、均线、动能、新闻/基本面、条件情景、风险和限制等章节。
- 图表：价格、量价、MA5/20/60、MACD、KDJ、RSI6/12/24；按 5/20/60 个交易记录或全部切换，可放大、复制和下载 CSV。报告可导出 Markdown。
- 追问：最多三个建议问题，点击填入现有 QuestionComposer，用户确认发送后执行新轮次；固定顶栏、浮动输入框和滚动到底部按钮沿用现有布局。
- 分享：公开已完成的报告、图表和校验状态；不公开执行历史、私有模型消息、checkpoint 或工具详情。

全部新增界面文案均提供简体中文、繁体中文和英文。共享控件使用 shadcn Base UI，图表使用官方 Chart 组件与 Recharts。

## 数据口径和边界

历史 K 线优先使用东方财富；预期的供应商错误自动切换到腾讯等效接口，覆盖沪深股票、指数、ETF 的日/周/月线。指数返回不复权点数，股票和 ETF 保留所请求的复权序列；派生指标、图表和可读事实使用同一口径。腾讯未提供的历史成交额、换手率保持空值；五分钟线和 `BK` 板块不会切换成不等效的数据。原始请求 `000001.SH / 2026-09-16–2026-10-08 / 15 条 / forward` 会按指数口径处理，在输出中标注 `adjustment=none`。

图表按真实日期使用命名列对齐，不通过数组位置猜测价格或均线。A 股成交量由手换算为股，柱形图从零开始；RSI 纵轴为 0–100，KDJ 的 J 可超出此范围。均线预热不足保持空值，不填零或复制收盘价。MACD 为 EMA12 − EMA26、DEA 为 EMA9、柱值为两倍差值；KDJ 为 9 日窗口，K/D 初始值 50；RSI 沿用窗口内平均涨跌幅算法，未宣称与所有行情软件完全一致。

价格保留前复权、不复权或后复权口径，图表展示所用数据的日期与来源。历史截止请求排除当前报价和估值；当前报价与日线日期不一致时分开展示并标记需核验。部分数据失败保留可用结果和明确限制，不能显示为全部采集成功。

行情断连、超时、熔断、无数据或上游响应格式变化由市场 Tool 的执行适配层返回安全失败包（无来源、无成功结果引用），让模型利用已取得的报价和搜索证据完成报告。失败调用先保存，不能伪装成成功快照。bundle 的部分采集失败继续保留成功分量；历史缺失时不重算或虚构趋势/技术图表。预算、Redis 治理、端点白名单、缓存摘要、租约、取消和持久化异常仍中止执行，不作为一般缺口吞掉。

当前直接行情工具仍限定于已验证的沪深 A 股；财报、资金流、分析师一致预期和港美股直接行情尚无相应结构化 Provider。因此截图中的资金分布图、完整财务表、港股联动和任意脚本执行尚未提供，不会生成虚构数据来补齐。财务和新闻分析可以引用搜索结果，无法取得证据时必须注明。

迁移 `009_security_research_instruments.sql` 幂等增加万科 A（000002.SZ）的名称和别名解析，保留已存在的证券记录。证券目录和交易日历仍需持续补充。

`resolve_instrument@1.0.0` 在目录未命中时，通过腾讯证券查询补查名称与裸代码，唯一候选再核验行情身份；完整沪深代码可直接用行情核验。江淮汽车无需增加单个硬编码映射即可解析为 `600418.SH`。多候选不自动选择；网络、预算、治理和完整性失败不再被吞成 `not_found`。查询响应使用现有 Gateway、真实调用预算及恢复快照，来源保留实际请求、原始摘要、时间与缓存状态，不将未经审核的候选写入永久目录。

## 验证与运行

离线测试使用实际 Provider 解析器、MockTransport 和 Pydantic AI FunctionModel，覆盖单次响应复用、指标预热、单位、日期对齐、部分失败、历史截止、图表证据、流式/非流式报告，以及权限和分享隔离，不调用付费模型。

完整后端测试须通过 `cogniz-api/scripts/test_isolated_database.py` 创建临时 schema；不可直接对用户数据库运行集成测试。另运行 `scripts/evaluate_agents.py` 和 Manifest 摘要门禁。前端执行类型检查、ESLint 和生产构建，并用模拟数据检查实际组件的图表、折叠、详情和追问交互；临时预览路由不发布。

部署继续使用现有 Compose，API、Taskiq Worker 和 maintenance 运行在同一个后端容器。升级后确认三个进程与健康检查正常。所有内置 Agents、Tools、Skills 只保留最新实现，唯一版本和依赖版本统一为 `1.0.0`；Skill 指令统一存放在 `instructions.md`。旧 Run 的版本和摘要不能改写；可使用 `python scripts/purge_incompatible_conversations.py` 预览，再显式加 `--apply` 清理不兼容对话、关联执行快照与工具结果，保留兼容对话和已结算用量，并暂停引用已删除对话的定时任务。
